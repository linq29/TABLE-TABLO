# TABLE-TABLO

学科が違う友人たちとの予定共有を、**1つの画面で素早く確認するための時間割メモ**です。  
「自分だけで確認する用（Solo Mode）」と「複数学科をまとめて確認する用（Crew Mode）」を切り替えて使えます。

## なぜ作るのか

所属学科が違う友人同士で予定を合わせるとき、
- 各自の時間割がバラバラで見づらい
- オンライン授業の会議ID/PWを毎回探すのが手間

といった悩みがありました。  
TABLE-TABLO は、これらを最小構成で解決するために作られたツールです。

## 機能

### 1. 時間割表示

#### Solo Mode
- 特定の１学科の時間割を表示
- 自分の授業確認に集中したいときに利用

#### Crew Mode
- **3つの学科の時間割**を1画面にまとめて確認
- セレクトメニューで表示対象の時間割を管理
- 友人との空き時間調整や集合時間の検討に便利

### 2. 備考欄（会議コード管理）
- オンラインクラスの **ID / PW** をメモ
- **ワンクリックでコピー**できる想定の欄を用意
- 授業開始直前でも素早く入室可能

## v1 の設計方針

GitHub Pages で簡単にデプロイできるよう、v1 は以下のシンプル構成にしています。

- フロントエンド: `HTML` / `CSS` / `JavaScript`
- データ管理: `JSON`
- サーバーサイド: なし（静的ホスティング前提）

つまり、**時間割や会議コードは JSON で管理し、表示は HTML 側で行う**構成です。


## ディレクトリ概要（v1）

- `index.html` : Crew Mode 画面
- `index-solo.html` : Solo Mode 画面
- `css/` : スタイル
- `js/` : 表示・操作ロジック
- `data/` : 時間割データ / 会議コードデータ（JSON）
